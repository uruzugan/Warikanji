# ワリカンジ

**いい幹事、いい感じ。**

ワリカンジは、旅行・飲み会・合宿などの複数人イベントで発生した費用を記録し、  
**誰が誰にいくら支払えば精算できるかまで自動計算するiOSアプリ**です。

## 主な機能

- イベント作成・編集
- 複数日イベント対応
- 参加者管理
- 費用の登録・編集・削除
- 均等割り / カスタム負担
- 端数処理
- 自動精算
- 支払い状況の管理
- レシート画像保存
- レシートOCR（店舗名・金額・日付・通貨の読み取り）
- 読み取り通貨からイベント通貨・参考通貨への概算換算
- 認識全文の端末内翻訳
- イベント・精算結果の共有
- 検索・並び替え
- アーカイブ / 復元
- イベント複製
- カレンダー連携
- 多言語・多通貨対応
- バックアップ・復元（レシート画像を含む）

対応言語は日本語、英語、簡体字中国語、繁体字中国語、韓国語、スペイン語、ポルトガル語です。

## 開発目的

複数人での旅行や飲み会では、それぞれが別々の費用を立て替えることがあります。

その際に発生する、

- 誰が何を支払ったかの記録
- 参加者ごとの負担額計算
- 誰が誰へいくら送金するかの計算
- 支払い状況の確認

といった幹事の負担を減らすことを目的に制作しました。

## テスト

`KanjiHelperTests` に、費用分担・端数処理・送金計算・通貨入力・旧形式データの互換性テストを用意しています。

```sh
xcodebuild -project KanjiHelper.xcodeproj \
  -scheme KanjiHelper \
  -destination 'platform=iOS Simulator,name=iPhone 16' \
  test
```

レシート全文の翻訳はAppleの仕様上、iOSシミュレータでは動作しません。iOS 18以降の実機で確認してください。
