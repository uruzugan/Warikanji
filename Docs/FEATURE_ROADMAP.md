# ワリカンジ次期機能ロードマップ

## 採用範囲

追加仕様の114項目はすべて長期ロードマップへ採用する。ただし、依存関係と安全性に従って段階実装する。

## Phase 0：リリース土台

完了済み。

- レシートOCR、通貨判定、参考換算、全文翻訳
- 7言語対応
- 保存失敗時の保護
- バックアップ・復元
- Privacy Manifest、権限文、公開文書草案
- 計算と旧データ互換テスト

## Phase 1：共通データ基盤

外部サービスなしで実装する。

- イベント種類別テンプレート
- 機能ON/OFF
- 主幹事、共同幹事、参加者、閲覧のみ
- 細分化した権限
- 参加者回答と共同編集の分離
- 一次会・二次会などの複数部
- 基本タスク、期限、担当者
- 編集履歴の器
- 進行アシスタントのルール基盤
- 旧イベントの自動移行

対象：1〜17、69〜79、114の共通部分。

## Phase 2：ローカル幹事機能

- 出欠、同伴者、遅刻・途中参加・退出
- 日程候補と投票
- 回答期限
- 食事制限、子ども区分
- 店候補の手動登録と投票
- 予約情報、確認、キャンセル期限
- 一杯目、集合、到着状況
- 予算、立替上限、会社補助
- 持ち物、担当、チェックリスト、タイムライン
- 席順、抽選、受付
- 終了まとめ、振り返り、店舗履歴、固定グループ

外部検索や共有がなくても幹事端末だけで利用できる範囲を先に完成させる。

### 現在の実装済み範囲

- 出欠、同伴者、子ども区分、食事制限、遅刻・途中参加・退出
- 一次会・二次会などの複数部と部ごとの出欠
- 日程候補、○△×回答、回答期限、確定日程
- 店・場所候補、○△×回答、候補決定
- 予約状態、予約番号、人数、連絡先、キャンセル期限
- 総予算、1人予算、幹事立替上限、会社補助、予算承認
- タスク、期限、担当者、幹事限定メモ
- 持ち物、数量、担当者、準備状態
- 当日のタイムライン、場所、担当者、実施状態
- 一杯目メニュー、アルコール区分、乾杯候補、第1〜第3希望、回答期限、集計
- 集合場所、集合時刻、目印、写真、参加者の到着状況一覧
- テーブル・席数、手動席割り、重複防止、ランダム席順
- 上記に対応した進行アシスタントの警告

## Phase 3：共有・共同編集

サービス選定後に実装する。

- 回答専用リンク
- 参加承認
- 未回答者リマインド
- 共同編集と権限検証
- 費用承認
- 編集履歴同期
- 精算ロック
- 一斉・緊急連絡
- 写真・紛失物・お礼の共有
- 幹事引き継ぎ

共有バックエンド、ログイン方式、通知費用、保存地域、削除方針を事前に決定する。

## Phase 4：外部情報連携

- 店検索、条件適合表示、地図
- 予約ページまたは予約API
- 飲み放題メニュー
- 天気
- 終電、交通、タクシー
- 現在地共有

利用規約、API料金、帰属表示、商用利用可否を個別に確認する。

## Phase 5：支払い連携

- 支払いQR・リンクの安全な共有
- 正式APIに対応した決済確認
- 予定額と実入金の照合
- 事前徴収

自己申告だけで支払い済みにする機能は実装しない。資金移動業、決済事業者規約、ストア審査への影響を確認してから進める。

## Phase 6：イベント別パック

- 旅行：共同財布、交通、車、部屋、ホテル、旅程
- BBQ・キャンプ：会場、食材、買い出し、道具、雨天代替
- ライブ・観戦：チケット、座席、受渡、遠征
- 同窓会：旧姓、卒業年度、クラス、名札
- サークル・部活：練習、備品、部費、遠征、当番
- 勉強会：テーマ、発表順、資料、タイマー、アンケート
- ゲーム会：ゲーム、人数、投票、チーム、順番
- 誕生日・送別会：主役、プレゼント、寄せ書き、ケーキ
- 結婚式二次会：受付、会費、景品、余興、役割
- 家族イベント：帰省、子ども、高齢者対応、食事

イベント別パックは共通のタスク、投票、予約、費用、タイムラインを組み合わせ、専用実装の重複を避ける。

## 相談が必要な選択

- 共有バックエンドと認証方式
- プッシュ通知サービスと運用費
- 店舗・地図・予約サービス
- 天気・交通情報の提供元
- 決済サービスとの正式連携範囲
- 写真共有の保存容量と保存期間
- 有料機能、サブスクリプション、利用上限

## 完了条件

各Phaseは次を満たしてから次へ進む。

- 旧データを読み込める
- 7言語で主要導線を利用できる
- 機能OFF時に不要なUIが出ない
- 権限外の操作をデータ層でも拒否する
- 計算結果と保存データに回帰がない
- バックアップと復元が新データを保持する
- 実機でアクセシビリティと主要権限を確認する
